# CSiamese 多语种论文网页 · 部署与使用说明

这是以 `CSiamese_html.zip` 为基础的静态网页改版。无须构建工具或后台服务，可以部署至 GitHub Pages、Netlify、Vercel 等静态网站服务。

## 文件清单

- `index.html`：网页主体、样式和科研内容（包含响应式布局）。
- `i18n.js`：英文、中文、俄语、法语、阿拉伯语的界面译文与交互逻辑；浏览器本地记忆语言选择。
- `images/`：原附件提供的全部 10 张图片和表格，文件名保持不变。
- `CSiamese.pdf`：原附件提供的论文 PDF。
- `CSiamese.bib`：由第二个附件 RIS 文献记录转换生成的 BibTeX，页面中的复制功能与该文件一致。
- `citation.ris`：用户提供的第二个附件引文记录，便于核对。
- `favicon.svg`：网站图标。

## 部署到 GitHub Pages

1. 新建或打开 GitHub 仓库。将此文件夹内的所有文件（包括 `index.html` 和 `images/` 文件夹）放置在仓库根目录；**不要只上传 ZIP 压缩包**。
2. 打开仓库 **Settings → Pages**，选择 **Deploy from a branch**，使用 `main` 分支和 `/ (root)` 目录并保存。
3. GitHub Pages 发布后，直接访问站点地址。若站点使用项目仓库路径，该页所有静态资源均使用相对路径，可正常加载。
4. 修改页面后提交文件，GitHub Pages 将重新发布。

## 页面功能

- 右上角语言菜单支持 `English / 中文 / Русский / Français / العربية`。阿拉伯语采用 RTL 从右向左布局，图表及 BibTeX 保持合适的阅读方向。
- 主体段落两端对齐，长段落自动换行；桌面、平板、手机自适应。
- 点击图表可放大查看；通过对话框中的关闭按钮或 Esc 键退出预览。
- 较宽的数据表在手机上支持横向滚动；附有原始表 5 的折叠查看区域。
- BibTeX 支持直接复制与下载 `.bib` 文件；科研原始数值和图表图片不会因切换语言而更改。
- 页面脚本、样式、图表均存放于本地；DOI 外链需要网络连接。
